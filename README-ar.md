# شبكة المعدات الطبية

يوفر هذا المشروع منصة متكاملة لربط وتكامل أنظمة المعدات الطبية. يركز على تصور الحالة، التشغيل البيني، والإدارة الموحدة للأجهزة الطبية المتنوعة بهدف تحسين كفاءة تشغيل المستشفى ورعاية المرضى.

## الميزات

- **تصور الأجهزة**: عرض الحالة الحالية واستخدام الأجهزة الطبية في الوقت الفعلي.
- **تكامل البيانات**: جمع ودمج البيانات من أجهزة غير متجانسة.
- **المراقبة عن بُعد**: تمكين الوصول والتحكم عن بُعد في الأجهزة المدعومة.
- **نظام التنبيهات والصيانة**: الكشف التلقائي عن الأعطال وإشعارات الصيانة.
- **إدارة المستخدمين والصلاحيات**: التحكم الآمن في الوصول حسب الدور (أطباء، فنيين، مدراء).
- **الإحصاءات والتقارير**: إنشاء تقارير استخدام الأجهزة وتحليلات تشغيلية.

## التقنيات المستخدمة

- الواجهة الأمامية: Vue.js  
- الواجهة الخلفية: Node.js / Python (FastAPI)  
- قواعد البيانات: MongoDB / MySQL  
- الاتصال: MQTT / WebSocket
