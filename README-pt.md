# Rede de Equipamentos Médicos

Este projeto oferece uma plataforma abrangente para a rede e integração de sistemas de equipamentos médicos. Foca na visualização, interoperabilidade e gestão unificada de dispositivos médicos, com o objetivo de melhorar a eficiência hospitalar e o atendimento ao paciente.

## Funcionalidades

- **Visualização de Dispositivos**: Visualização em tempo real do status e uso dos equipamentos médicos.
- **Integração de Dados**: Coleta e integração de dados de dispositivos heterogêneos.
- **Monitoramento Remoto**: Acesso e controle remoto de dispositivos compatíveis.
- **Sistema de Alertas e Manutenção**: Detecção automática de falhas e notificações de manutenção.
- **Gestão de Usuários e Permissões**: Controle de acesso seguro por função (médicos, técnicos, administradores).
- **Estatísticas e Relatórios**: Geração de relatórios de uso e análises operacionais.

## Tecnologias Utilizadas

- Frontend: Vue.js  
- Backend: Node.js / Python (FastAPI)  
- Banco de Dados: MongoDB / MySQL  
- Comunicação: MQTT / WebSocket
