# Red de Equipos Médicos

Este proyecto proporciona una plataforma integral para la interconexión e integración de sistemas de equipos médicos. Se centra en la visualización, interoperabilidad y gestión unificada de diversos dispositivos médicos, con el objetivo de mejorar la eficiencia hospitalaria y la atención al paciente.

## Características

- **Visualización de Dispositivos**: Visualización en tiempo real del estado y uso de los equipos médicos.
- **Integración de Datos**: Recopilación e integración de datos de dispositivos heterogéneos.
- **Monitoreo Remoto**: Acceso y control remoto de dispositivos compatibles.
- **Sistema de Alertas y Mantenimiento**: Detección automática de fallas y notificaciones de mantenimiento.
- **Gestión de Usuarios y Permisos**: Control de acceso seguro por rol (médicos, técnicos, administradores).
- **Estadísticas e Informes**: Generación de informes de uso de dispositivos y análisis operativos.

## Tecnologías Usadas

- Frontend: Vue.js  
- Backend: Node.js / Python (FastAPI)  
- Base de Datos: MongoDB / MySQL  
- Comunicación: MQTT / WebSocket
